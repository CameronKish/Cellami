📋 Cellami - Certification Testing Guide

App Name: Cellami

Version: 1.2.0

Publisher: Cameron Kish

Category: Productivity / AI Assistant

Platform: Excel (Desktop & Online)

1. Overview

Cellami is a privacy-focused AI assistant that runs entirely on the user's local machine. It integrates with Excel to provide AI-powered data analysis, document Q&A, and conversational capabilities.

⚠️ Important: This add-in requires a companion desktop application (Cellami.app for Mac or Cellami.exe for Windows) to function. The add-in alone will not work without the desktop app running.

2. Testing Requirements

3. Installation Steps

Step 1: Install Ollama

  1. Download Ollama from ollama.com
  2. Install and launch Ollama
  3. Open Terminal (Mac) or Command Prompt (Windows)
  4. Run: ollama pull gemma3:4b
  5. Wait for the model to download (~3GB)

Step 2: Install Cellami Desktop App

Download the appropriate version from GitHub Releases:

For Mac:

  1. Download Cellami_Mac.zip
  2. Unzip the file
  3. Move Cellami.app to Applications folder
  4. Right-click → Open (first time only, to bypass Gatekeeper)
  5. Look for Cellami icon in the menu bar (top-right of screen)

For Windows:

  1. Download Cellami-Windows-x64.zip
  2. Extract the zip file (Right-click → Extract All)
  3. Run Cellami.exe
  4. Allow any firewall/security prompts
  5. Look for Cellami icon in the system tray (bottom-right of screen)

Step 3: Load the Add-in in Excel

You can test the add-in in either Excel Desktop or Excel Online (browser). Both methods work, but Excel Online is the easiest for testing:

Option A: Excel Online (Recommended for Testing)

  1. Go to excel.office.com in your browser (Refer to "6. Browser Compatibility").
  2. Create or open a workbook
  3. Go to Insert → Add-ins → Upload My Add-in
  4. Upload the Cellami manifest file
  5. The Cellami panel will appear on the right side

Option B: Excel Desktop

  1. Open Microsoft Excel on your computer
  2. Go to Insert → My Add-ins
  3. Load the Cellami add-in
  4. The Cellami panel will appear on the right side

4. Feature Testing Guide

Feature 1: Chat with Data

Description: Have a free-form conversation with your spreadsheet data. Ask questions, get summaries, and receive AI-powered insights.

How to Test:

  1. Enter some sample data in Excel (e.g., sales figures, names, dates)
  2. Open the Cellami panel
  3. Go to the "Chat" tab
  4. Type a question like "Summarize this data" or "What's the total?"
  5. Verify the AI responds with relevant information (make sure you click the icon to add cell data to the prompt).

Feature 2: Query Cells

Description: Select specific cells and ask the AI to process, analyze, or transform the data.

How to Test:

  1. Select one or more cells containing data
  2. Use the "Query" feature in the Cellami panel
  3. Ask a question about the selected data
  4. Verify the AI response is contextually relevant to the selection

Feature 3: Query Tables

Description: Analyze entire tables at once. Select a range of data for comprehensive insights.

How to Test:

  1. Create a table with multiple rows and columns
  2. Select the entire table range
  3. Ask the AI to analyze trends, find patterns, or summarize
  4. Verify the response considers the full table context

Feature 4: Knowledge Base

Description: Upload documents (PDF, Word) and ask questions based on their content.

How to Test:

  1. Go to the "Knowledge Base" tab
  2. Upload a test document (PDF or DOCX)
  3. Wait for processing to complete
  4. Ask a question related to the document's content
  5. Verify the AI uses document context in its response

Feature 5: Audit Trail

Description: View which document chunks were used to generate each response for transparency.

How to Test:

  1. After receiving a Knowledge Base response (through a chat, cell query, or table query), click "Audit"
  2. Verify source citations are displayed
  3. Confirm the cited passages match the response context
